# 实体施工阶段专业知识库 (Construction Phase Knowledge Base)

> 用途：为 pmp-lead-pm-scheduler 的 4 套 WBS 模板提供**专业施工工序与验收闸口**的权威依据。
> 所有数据点均标注国家标准出处，禁止臆造工期或闸口。

## 1. 专业施工工序总逻辑 (office / lab fitout)

工装施工遵循 **"先基础后精细、先隐蔽后明面、先硬装后软装"** 的分层推进原则
（来源：办公楼装修施工流程行业共识，天元世纪/超级家贝等工装施工单位公开工艺说明）。

标准 D&B / DBB 办公 fitout 实体施工顺序（不可跳步）：

1. 场地移交 / 动工准备 / 测量放线
2. 临时设施与场地保护
3. 原装修拆除清运（如涉改造）
4. **隔墙轻钢龙骨骨架搭设** + 机电管线穿墙预埋
5. ★ **隔墙隐蔽验收 (Partition Concealed Acceptance)** —— 见 §2
6. 大机电主管桥架 / 吊顶龙骨 + 吊顶内机电末端
7. ★ **吊顶/顶棚隐蔽验收 (Ceiling Concealed Acceptance)** —— 见 §2（封板前必做）
8. 封板 / 饰面 / 墙顶工程
9. 地坪工程
10. 末端 IT/弱电/安防/灯具安装
11. 测试与联调 (T&C) / 系统联动
12. 缺陷整改
13. ★ **[M] 施工全部完成及承包商自检通过**
14. ★ **竣工初验 / 实际竣工 (Practical Completion · 五方初验)** —— 见 §3
15. **办公家具进场与安装 (Furniture Delivery & Installation)** —— 见 §4
16. 消防专项验收（建管/住建）
17. 联合竣工备案 / 竣工验收通过
18. 室内空气双盲检测 (IAQ，须家具就位后) —— 见 §4
19. 客户搬迁入驻

## 2. 隐蔽工程验收法定闸口 (GB 50210-2018)

《建筑装饰装修工程质量验收标准》GB 50210-2018 明确将**隔墙**与**吊顶**列为两道**独立**
隐蔽工程验收，且**吊顶面板封闭前必须完成吊顶内管道设备调试及验收**。

### 2.1 隔墙隐蔽验收 — 8.1.4 轻质隔墙工程
应验收项目：
- 骨架隔墙中设备管线的安装及水管试压
- 木龙骨防火、防腐处理
- 预埋件或拉结筋
- 龙骨安装
- 填充材料的设置

→ 时序：隔墙骨架 + 机电穿墙预埋完成、**封板/饰面前**验收。

### 2.2 吊顶/顶棚隐蔽验收 — 7.1.4 / 7.1.10 吊顶工程
应验收项目（7.1.4）：
- 吊顶内管道、设备的安装及水管试压、风管严密性检验
- 木龙骨防火、防腐处理
- 埋件、吊杆安装、龙骨安装、填充材料的设置、反支撑及钢结构转换层

强制性时序（7.1.10）：
> **"安装面板前应完成吊顶内管道和设备的调试及验收。"**

→ 时序：吊顶龙骨 + 吊顶内机电/消防末端完成、**封板（吊顶面板封闭）前**验收。
> 7 天施工日历下该闸口随施工日历排布；检查由甲方/监理/质检参与，为受控事件。

## 3. 竣工验收法定程序 (实际竣工 / 初验 / 专项 / 备案)

依据《建设工程质量管理条例》及地方政府投资项目竣工验收办法（延长县、海盐县、莲都区等
政府验收文件口径一致）：

- **施工单位自检**：工程完工后施工单位全面自检，提交竣工报告。
- **竣工初验 / 实际竣工 (Practical Completion)**：建设单位组织 勘察、设计、施工、监理
  （及使用方）进行初验，形成初验报告与整改清单。规模较大/复杂项目必须先初验后竣工验收。
- **专项验收**：消防、环保、人防、档案等在竣工验收前完成（消防为合法使用红线）。
- **竣工验收 / 联合验收备案**：建设单位组织，验收合格 → 备案。

模板落点：
- `[M] 施工全部完成及自检通过` = 承包商自检完成（works complete）。
- `[M] 竣工初验 / 实际竣工 (Practical Completion · 五方初验)` = 建设单位五方初验闸口
  （本知识库新增，置于自检之后、家具进场之前）。

## 4. 家具供货与进场协调机制 (Furniture Coordination)

家具在排程中须分两层处理，禁止把"物理进场"与"长周期采购"混为一谈：

- **长周期采购 (Long-lead Procurement)**：家具供应商定标 + 生产交货 Lead Time 应在
  **Phase 5（施工阶段并行）**启动，确保硬装收尾时家具已到货待装。属采购活动，不影响
  施工关键路径的"封板/饰面"逻辑。
- **物理进场与安装 (Physical Delivery & Installation)**：必须排在 **竣工初验 / 实际竣工
  (Practical Completion) 之后**——此时空间已完工、清洁、受保护（weather-tight），避免
  粉尘/磕碰损坏家具；且须排在 **IAQ 双盲检测之前**，因为家具是 VOC/甲醛的主要释放源，
  盲测必须覆盖家具就位后的真实空气质量（GB 50325 甲醛/TVOC 限值）。

模板落点：
- Variant A (D&B)：原模板**缺失**物理家具进场节点 → 本修复**新增** `办公家具进场与安装`
  （置于初验后、IAQ 前）。
- Variant B (DBB)：原节点 `办公家具进场组装` 误置于施工自检**之前** → 本修复**迁移**至
  初验之后、IAQ 之前。

## 6. 日历语义与排程政策（用户决策基线，2026-08-27 锁定）

本节固化三轮 P0 缺陷修复后沉淀的四条排程政策，作为 solver_engine 与 mpp_renderer
两引擎的**唯一权威口径**，杜绝求解器日志与 MPP 实测二次漂移。

### 6.1 7 天施工日历语义（仅春节→元宵停工）

- **规则**：实体施工阶段（含 Ph4 施工、Ph5/Ph6 收尾）套用「施工 7 天日历」——
  **周末照常施工；全年仅「春节 → 元宵（正月十五）返岗」区间停工**，其余所有法定节假日
  （国庆、劳动节、清明、元旦、端午、中秋等）**一律照常施工**。
- **依据**：用户明确裁决「7天施工日历除了春节到元宵之间不施工，其余都要施工」。
  该口径已对齐 MPP `施工7天日历` 物理注入的例外策略（`holidays.json` 仅挂
  「春节元宵大假」2027-02-06→02-20 一段，含「春节」关键词，双引擎 filter 一致命中）。
- **双引擎实现**：
  - `solver_engine.py _is_working_day`：`work_weekend=True` 时周一~周五仅排除
    `spring_festival_bitmap`（春节位图），其余法定节假日 `holiday_bitmap` **不生效**，周末恒工作。
  - `mpp_renderer`：施工日历例外日仅挂春节区间，国庆/劳动节/清明等无例外 → 照常排程。

### 6.2 政府审批/报建阶段强制 5 天日历

- **规则**：施工许可证办理、图审合格证、质安监报监、各类审批类节点属**法定行政行为**，
  周末与法定节假日均不办公 → **强制标准 5 天日历，绝不可套用施工 7 天日历**。
- **双引擎对齐**（修复前摘要名含「施工」误套 7 天，造成 ~4 天求解器/MPP 漂移）：
  - `solver_engine.py`：新增 `GOV_APPROVAL_KEYWORDS = {"施工许可证","许可证办理","图审合格证","质安监报监"}`，
    命中即 `work_weekend=False`。
  - `_common.py`：新增 `_GOV_APPROVAL_EXCLUDE_KEYWORDS`（含「审批」），
    `create_task_with_outline` 在判定 `is_construction_summary` 时显式排除，
    避免摘要名含「施工」误派 7 天。
- **验证**：MS Project COM 实测 `output_mpp/S1~S4.mpp`、`Hefei_500_DB_invite.mpp`
  报建阶段均落「无（标准 5 天）」日历，与求解器一致。

### 6.3 家具进场夹于两次 IAQ 之间（用户决策）

- **规则（用户原话）**：「家具安装在第一次空气检测之后、第二次空气检测之前」。
- **工艺依据**（§4 已述）：家具为 VOC/甲醛主释放源（GB 50325 限值），
  首次盲测须先测硬装基底，家具就位后再做二次复测覆盖真实空气质量；且家具须在
  竣工初验（空间 weather-tight）之后进场，避免粉尘/磕碰损坏。
- **实现**：`rewire_furniture.py` 按名称重连——
  `首次室内空气盲测 → 办公家具进场与安装 → 二次室内空气质量复测`；
  **并物理 relocate 家具节点至首次IAQ 之后**（保持 CPM 拓扑序，避免
  `min() iterable empty` 崩溃）。4 套模板已全部重连+落位。
- **消防预验收**同步改为排在「竣工初验」之后（原 DBB 误排于家具之后）。

### 6.4 隔墙隐蔽 → 吊顶隐蔽 至少 2 周（按面积放大，中间穿插工序）

- **规则（用户原话）**：「隔墙隐蔽验收后至少 2 周后才会有天花隐蔽验收，根据面积大小
  情况而往后加大天数，但这两个之间应该有其他工序的安排穿插」。
- **工艺依据**（§2）：GB 50210-2018 §7.1.10 强制「封板前须完成吊顶内管道设备调试及验收」；
  吊顶内机电管线须先于龙骨封板，故两道隐蔽闸口之间需穿插**大机电主管桥架 / 吊顶龙骨 /
  二次机电**等实体工序，不可空等。
- **实现**：`calibration.py` 新增 `INTERSPERSED_TRADE_MIN_DAYS = 14` 与
  `INTERSPERSED_TRADE_KEYWORDS`，对上述穿插工序设工期下限 `max(base_dur, 14)`；
  面积放大经 `scale_factor = (area/base)^0.3` 自然拉大间隔，小面积也不低于 14 天。
- **模板落点**：D&B 模板在 `隔墙隐蔽(42)` → `吊顶隐蔽(1601)` 间穿插 `大机电(id40)`；
  DBB 模板在 `隔墙隐蔽(35)` → `吊顶隐蔽(53)` 间穿插 `吊顶龙骨(36)`+`二次机电(37)`。

### 6.5 倒排锚点校准

- `solve_schedule_with_target`（倒排）返回 `finish_date` = **搬迁锚点日**，非真实末任务 finish。
  `main.py` 以 `max(t.finish)` 修正「项目终点」日志，避免比 MPP 少算搬迁尾段
  （约 7 天）造成虚假漂移。MPP 仍为工期最终权威，求解器日志仅作预览/审计。
