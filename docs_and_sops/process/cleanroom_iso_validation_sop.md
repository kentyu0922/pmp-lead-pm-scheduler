# 🏗️ 专家 B：高洁净度实验室/洁净室 (ISO 5~8) 专项工序 SOP (SOP-B2)

## 1. 适用场景
适用于生物医药实验室、半导体洁净车间、无菌检验室及 ISO 5 (100级)、ISO 7 (10000级)、ISO 8 (100000级) 洁净工程。

## 2. 刚性工序与第三方 ISO 验证流程
1. **FFU / 高效过滤器 HEPA 检漏测试** (2工日)
2. **洁净室风速、换气次数及风量平衡测试** (2工日)
3. **洁净区压差梯度（正压/负压）测试与调试** (2工日)
4. **悬浮粒子计数与沉降菌采样测试** (2工日)
5. **第三方 ISO 等级验证报告出具** (2工日)

```text
硬装及防静电地坪完工 ➔ FFU/HEPA 检漏 ➔ 压差梯度调试 ➔ 悬浮粒子/沉降菌测试 ➔ 第三方 ISO 认证报告 ➔ 交付
```
