# 🏗️ 专家 B：数据中心 / 计算机机房 (IDC Tier III/IV) 专项测试与全系统联调 SOP (SOP-B3)

> **适用范围**：金融行业数据中心、大型互联网企业 IDC 核心机房、企业总部核心网络中枢及 A级 / Tier III / Tier IV 级别算力中心机电建设项目。  
> **核心标准**：GB 50174-2017《数据中心设计规范》、GB/T 2887-2011《计算机场地通用规范》、TIA-942-B《Telecommunications Infrastructure Standard for Data Centers》、ASHRAE TC 9.9 热指南。

## 1. 数据中心等级划分与容错冗余基准

| 等级划分 | 架构标准 | 供配电冗余拓扑 | 暖通制冷拓扑 | 连续运行可用性指标 | 关键容错特性 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **GB 50174 A 级** / **Tier IV** | 容错型 (Fault Tolerant) | 2(N+1) 双母线或 2N | 2N 或 2(N+1) 独立回路 | 99.995% (年停机≤0.4h) | 任一系统发生单点故障时不影响 IT 设备运行；电气与管道物理隔离 |
| **GB 50174 B 级** / **Tier III** | 同时可维护型 (Concurrently Maintainable) | N+1 或 2N 冗余路径 | N+1 备用机组与环形管网 | 99.982% (年停机≤1.6h) | 计划性维护活动无需关闭 IT 载荷；双路市电配柴油发电机应急保障 |
| **GB 50174 C 级** / **Tier II** | 基本冗余型 | N+1 关键部件冗余 | N+1 单循环制冷系统 | 99.741% (年停机≤22.7h) | 维护需配合维护窗口停机 |

## 3. 刚性核心测试工序流程与工期分解

在现场施工收尾、正式双路市电受电成功后，进入为期 **15 个工作日**的刚性测试与验证阶段：

```text
双路高低压送电 + 机柜机电配线 
              │
              ▼
【工序 1】 双路市电与柴油发电机 ATS 自动投切与带载测试 (2 工日)
              │
              ▼
【工序 2】 精密空调 (CRAC) 冷热通道气流组织与温湿度联调 (3 工日)
              │
              ▼
【工序 3】 大容量 UPS 蓄电池组满载恒流放电及热成像巡检 (2 工日)
              │
              ▼
【工序 4】 假负载 (Load Bank) 连续 72h 全负荷极限工况烤机 (5 工日)
              │
              ▼
【工序 5】 综合系统故障注入 (Black Hole Test) 与第三方认证移交 (3 工日)
              │
              ▼
【里程碑】 交付业主网络与服务器运维团队进场铺底上架
```

### 3.1 工序 1：双路市电与发电机 ATS 自动切换测试 (2 工日)
- **试验内容**：
  - 双路市电相互备用自投自复功能测试；
  - 人工切断一路市电、模拟外电全部中断工况，触发柴油发电机组自启动并联送电。
- **关键性能指标 (KPI)**：
  - 柴油发电机从市电失电到稳定建压、ATS 开关完成闭合切换的总时间必须 **≤ 15 秒**；
  - 切换瞬间母线电压暂降与暂升幅值在 IT 设备容忍范围（CBEMA / ITIC 曲线以内）。

### 3.2 工序 2：精密空调 (CRAC/CRAH) 与冷热通道封闭调试 (3 工日)
- **试验内容**：
  - 封闭冷通道（或热通道）的气密性检查；
  - EC 风机转速与送风静压箱压力联动变频测试；
  - 备用空调机组故障自动轮值切换（N+1 倒换试验）。
- **关键指标**：
  - 机房冷通道温度稳定在 **18℃ ~ 27℃**，相对湿度控制在 **40% ~ 60%**；
  - 机柜进风面垂直方向（上、中、下）温差 **≤ 3℃**，无局部热点聚集与冷风短路。

### 3.3 工序 3：大容量 UPS 蓄电池组满载放电续航测试 (2 工日)
- **试验内容**：
  - 投入假负载箱使 UPS 主机达到 100% 额定标称容量；
  - 断开整流器输入交流电源，转为电池组纯直流逆变放电；
  - 全过程采用高分辨率红外热成像仪对电池极柱、连接铜排、直流断路器触头进行实时测温。
- **关键指标**：
  - 电池组在 100% 额定负荷下连续放电时间必须 **≥ 30 分钟**（或设计要求值）；
  - 单体电池端电压压差在允许偏差内，电池接线端子温升 **≤ 25K**，无异常发热或鼓包。

### 3.4 工序 4：假负载 (Load Bank Testing) 72 小时全负荷烤机测试 (5 工日)
- **测试环境构建**：
  - 在每个服务器机柜内安装 3~6kW 阻性假负载发热加热器（模拟服务器发热量及吸风量）；
  - 全场按 25%、50%、75%、100% 负荷阶梯式递增投入；
  - 满负荷连续运行 **72 小时**，不间断监测配电母线、PDU、制冷量匹配及消防气体释放联锁。
- **合格判据**：
  - 72 小时连续运行期间，供电母线温升稳定，无断路器跳闸；
  - 制冷系统热交换效率良好，出水/进水温差稳定，未触发高温告警。

### 3.5 工序 5：极端故障注入测试与第三方 Uptime/CQC 验证 (3 工日)
- **黑灯断电测试 (Black Building Test)**：
  - 在全负荷运行工况下，手动拉闸切断大楼进线总开关，验证 UPS 瞬态接管、柴油发电机自启动、应急空调冷冻水蓄冷罐二次释冷能力。
- **第三方报告**：
  - 出具第三方测试机构（或 Uptime Institute / 中国质量认证中心 CQC）的正式验证合格报告并签署移交清单。

## 4. PMP 排期与关键路径约束

1. **先决依赖**：
   - 数据中心必须单独作为 WBS 关键子模块（Add-on: `datacenter_add_on`）；
   - 前置必须绝对依赖：`大楼正式双路高压受电完成`、`消防气体灭火系统（IG541/七氟丙烷）管网打压与联动验收完毕`。
2. **后置硬依赖**：
   - 机房测试未出具合格报告前，**严禁业主 IT 服务器、核心网络交换机物理上架通电**。
