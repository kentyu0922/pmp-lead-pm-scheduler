# 🏗️ 专家 B：数据中心 / 计算机机房 (IDC Tier III/IV) 专项测试 SOP (SOP-B3)

## 1. 适用场景
适用于企业核心机房、金融数据中心及 A级 / Tier III / Tier IV 级别 IDC 机房建设。

## 2. 刚性调试与假负载测试流程
1. **双路市电与发电机 ATS 自动切换测试** (2工日)
2. **精密空调 (CRAC) 与冷热通道气流组织联动调试** (3工日)
3. **大容量 UPS 蓄电池组满载放电续航测试** (2工日)
4. **假负载全负荷测试 (Load Bank Testing)** (5工日)：模拟机柜 100% 发热全负荷连续运转 72 小时。
5. **Uptime / CQC 验证与正式移交** (3工日)。

```text
机电及机柜就位 ➔ 双路市电/ATS切换 ➔ 精密空调气流调试 ➔ UPS满载放电 ➔ 假负载 Load Bank 72h全负荷测试 ➔ Uptime/CQC 验证 ➔ 移交
```
