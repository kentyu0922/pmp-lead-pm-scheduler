# 🛡️ 建设工程质量安全监督手续与施工许可证并联申报 SOP (Safety Supervision & Permit SOP)

> **适用范围**：中国大陆境内商业办公室内装修工程（工装）、研发中心及实验设施建设项目。  
> **核心目标**：指导项目经理（Lead PM）与报建专员合规、高效完成「工程质量安全监督申报（报监）」与「建筑工程施工许可证」的并联申办，保障开工合法性，杜绝因无证施工被建管部门处罚或停工。

---

## 1. 法律法规与政策依据

本 SOP 依据住建部及属地住建行政主管部门现行强制法规制定：
1. **《中华人民共和国建筑法》**（主席令第29号修正）第七条、第八条：建筑工程开工前，建设单位应当按照国家有关规定向工程所在地县级以上人民政府建设行政主管部门申请领取施工许可证。
2. **《建设工程质量管理条例》**（国务院令第279号，第714号修订）第十三条：建设单位在开工前，应当按照国家有关规定办理工程质量监督手续。
3. **《建设工程安全生产管理条例》**（国务院令第393号）第十条：建设单位在申请领取施工许可证时，应当提供建设工程有关安全施工措施的资料。
4. **《房屋建筑和市政基础设施工程施工安全监督规定》**（住建部令第25号）：工程开工前，建设单位应办理施工安全监督手续并提供安全生产保障措施资料。
5. **《危险性较大的分部分项工程安全管理规定》**（住建部令第37号）：施工单位应在施工前编制危大工程专项施工方案；超规模危大工程应组织专家论证。

## 3. 标准并联办理流程与时效控制

现代政务服务网及「工程建设项目审批管理系统（工改系统）」已全面推行**「多审合一、并联审批」**。

```text
施工图审合格 + 施工/监理合同签订 
              │
              ▼
┌─────────────────────────────────────────────────────────────┐
│              住建部/属地政务网工改系统一窗并联申报             │
├──────────────────────────────┬──────────────────────────────┤
│    轨道 A：工程质量安全监督手续    │   轨道 B：建筑工程施工许可证申办   │
│  - 质安监机构线上受理与材料核验  │  - 建设资金与用地/规划条件核验 │
│  - 安全文明施工措施费拨付审查    │  - 施工总包/项目经理资质线上核验│
│  - 分配属地质监员与安监员监督组  │  - 审批决定与电子证照生成      │
└──────────────────────────────┴──────────────────────────────┘
              │                              │
              └──────────────┬───────────────┘
                             ▼
     【里程碑】取得电子版《建筑工程施工许可证》 (核发窗口：5~8 工作日)
                             │
                             ▼
              开工前安全生产条件现场踏勘核验 (1~2 工作日)
                             │
                             ▼
              【里程碑】工程正式开工 / 场地移交全面动工
```

### 3.1 审批时限标准
- **法定承诺办理时限**：各省市工改系统承诺办理时限通常为 **5~8 个工作日**（如上海 5 工日、深圳 3~5 工日、杭州 5 工日、北京 5 工日）。
- **风险缓冲建议**：在 MS Project 排期计划中，建议为报建审批窗口安排 **5~8 个工作日**，并在设计深化与总包招标期间前置准备社保凭证与保函，严禁临期突击补办导致开工延期。

## 4. 现场开工前安全生产条件核验清单（现场踏勘）

在取得施工许可证后、实质性拆除或机电打眼施工前，属地安监站（或网格化建管巡查组）将进行开工前现场安全生产条件抽查核验：

- [ ] **项目现场封闭管理**：施工界面围挡、大门、门禁系统及实名制考勤闸机已布设完毕。
- [ ] **关键岗位人员到岗**：项目经理（一级/二级建造师注册证书及安全 B 证）、专职安全员（安全 C 证）、总监理工程师现场到位并完成实名制考勤绑定。
- [ ] **临时用电标准化规范**：现场配备标准一级/二级配电箱，实行「三级配电、两级漏电保护、一机一闸一漏一箱」标准，电缆无裸露乱拉。
- [ ] **临时消防保障设施**：大楼物业已批准动火报备，现场每 50㎡ 至少配备一组（2具）4kg ABC 干粉灭火器，临时消防管网及消防水桶就位。
- [ ] **危大工程管理台账**：超过一定规模的脚手架、高处作业吊篮、大型设备吊装及结构拆除专项施工方案已由总包技术负责人、总监理工程师双签字审批。

## 5. PMP 排期与 WBS 逻辑锚定规则

在 MS Project 及 `pmp-lead-pm-scheduler` 系统中，质安监报监与施工许可的编排刚性遵循以下契约：

1. **前置任务依赖 (Predecessors)**：
   - 依赖「第三方施工图联合审查合格」（FS）
   - 依赖「施工总包定标与施工合同签订」（FS）
   - 依赖「大楼物业进场装修手续与施工图纸送审同意」（FS 或 SS+lag）
2. **后置任务约束 (Successors)**：
   - 后置紧跟「[M] 正式取得施工许可证（核发）」
   - 进而驱动「场地正式移交 / 施工放线与原建筑保护工程」
3. **免办折叠逻辑 (Fold Exempt)**：
   - 若项目经 `permit_expert.py` 判定为 `is_exempt=True`（低于城市免办面积与造价门槛），系统调用 `fold_exempt_construction_permit` 自动剔除政府报监与政府许可证申请节点。
   - **红线**：政府报建节点可折叠，但大楼物业消防安全协议、大楼物业图审与进场手续绝不可折叠！
