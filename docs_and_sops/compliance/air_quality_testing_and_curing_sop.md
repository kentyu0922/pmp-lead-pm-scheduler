# 两次室内空气质量检测与光触媒治理 SOP 规范指南

## 1. 概述
在所有办公工装及研发实验室项目中，**室内空气质量检测必须分为两次独立阶段进行**。严禁将空气检测压缩为一次，或在软装进场前直接出具最终报告。

---

## 2. 两次室内空气检测与治理的标准 SOP 流程

```text
硬装竣工/粗保洁 ──> 1. 首次空气盲测 (测试基材) ──> 2. 光触媒全场高温喷涂/强排风 (7-10d)
                                                                 │
员工正式搬迁入住 ◄── 4. 二次全场空气复测 ◄── 3. 实验台柜及办公家具/软装进场
```

### Ⅰ. 首次室内空气质量采样盲测 (基材/涂料测试)
- **触发条件**：硬装施工收尾、防静电环氧地坪硬化完成、HVAC 单机调试后、粗保洁完毕。
- **检测目的**：评估建筑墙体底漆、石膏板、粘结胶水及地坪基材的甲醛、苯系物、TVOC 释放量。
- **工期**：3 个工作日（含现场多点密闭采样与实验室分析）。

### Ⅱ. 光触媒治理与强制通风散味
- **治理手段**：全场高压喷涂光触媒/纳米二氧化钛，开启大功率工业排风机及 HVAC 空调最大换气量。
- **静置时间**：**5 - 7 个日历日**。

### Ⅲ. 实验台柜、通风柜及办公家具配送安装
- **进场安装**：实验室专用全钢/钢木实验台、防爆通风柜、气瓶柜及办公区域系统家具配送就位。
- **工期**：4 - 8 个工作日。

### Ⅳ. 竣工强排通风与空气净化散味阶段 (SOP-4)
- **夏季完工 (6-8月)**：45 工日 (60 日历日)。
- **春秋季完工 (3-5月, 9-10月)**：60 工日 (90 日历日 / 3 个月)。
- **冬季完工 (11-2月)**：75 工日 (110 日历日)。

### Ⅴ. 二次全场室内空气质量正式复测 (正式报告)
- **检测目的**：在家具及软装全部进场后，进行全场最终室内空气质量正式检测。
- **采样点设置**：按国标 GB 50325 / GB/T 18883 标准多点密闭采样。
- **工期**：4 - 5 个工作日（出具盖章的正式空气检测检测报告）。
