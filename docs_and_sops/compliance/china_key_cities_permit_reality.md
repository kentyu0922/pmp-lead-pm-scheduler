# 全国关键城市（杭州/合肥/天津/苏州/上海/北京/深圳/广州/成都/武汉等）属地化报建与消防/竣工验收刚性时效指南

## 1. 概述与核心法则 (Overview & Core Principles)

### 城市规则库单源法则
城市免办限额与消防审查时效以 `config/city_permit.json` 内置规则库为准（随仓库发布、可审计、可复核）。未收录城市回退「全国通用标准」静态兜底；本系统不发起任何实时网络检索，避免不确定性与外部依赖，所有规则均可离线复现。

### 刚性计算防线原则
1. **地方专有门槛实时检索校验**：抓取所在城市最新的免办限额（如：浙江/杭州为 1000m² 且 200万元 以下免办，上海/苏州为 300m² 且 100万元 以下免办等）。
2. **施工前报批阶段**（若属于强制报建范畴）：含施工图审查、消防设计审查、施工许可证核发，刚性下限为 **10 - 15 个工作日**。
3. **免办项目快速通道**（若属于免办小型工程范畴）：强扣免办《施工许可证》，省去政府图审与发证环节，仅保留大楼物业二次装修审查与协议签署（**3 - 5 个工作日**）。
4. **竣工验收与备案阶段**：含消防现场实测抽查、住建联合竣工验收备案，刚性下限为 **15 - 25 个工作日**。

## 2. 核心城市属地化报建与门槛清单

- **杭州**：建筑面积 < 1000m² 或 造价 < 200万元 免办《施工许可证》（浙建〔2020〕18号）。
- **上海**：建筑面积 < 300m² 且 造价 < 100万元 免办（沪建规范〔2020〕8号）。
- **北京**：建筑面积 < 500m² 且 造价 < 100万元 免办（京建法〔2021〕8号）。
- **深圳**：建筑面积 < 500m² 或 造价 < 100万元 免办（深府办规〔2025〕3号）。
- **广州**：建筑面积 < 500m² 或 造价 < 200万元 免办（粤建规范〔2020〕2号）。
- **苏州/成都/武汉**：建筑面积 < 300m² 且 造价 < 100万元 免办。
