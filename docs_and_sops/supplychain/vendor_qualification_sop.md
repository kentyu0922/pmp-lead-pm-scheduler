# 📦 专家 C：供应商实缴资质与双城支援履约评估 SOP (SOP-C3)

## 1. 资质与资金评估门槛
- **实缴资本门槛**：实缴资本 **1,000 万元人民币以上**，无重大法律诉讼与失信记录。
- **履约能力评估**：具备自有制造基地或全国一级直营授权。

## 2. 双城联动支援能力 (如 杭州/成都 双城联动)
在跨区域多基地项目中，优先推荐具备“**杭州 + 成都双城直营/服务网络**”的品牌（如圣奥 Sunon、诺梵 NOVAH、玛祖铭立 MATSU、海太欧林 ONLEAD）：
- **统一框架折扣**：两地合并计算体量获取更高采购折扣。
- **双城 24h 本地售后**：两地均设直属仓储与售后团队，保障补货与检修时效。
