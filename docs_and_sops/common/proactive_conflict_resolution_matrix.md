# 🛠️ 冲突消解矩阵 (Proactive Conflict Resolution Matrix)

当遇到工程限制、施工限制或目标日期冲突时，系统采用以下规则矩阵消解：

| 冲突场景 | 触发条件 | 消解策略与逻辑算法 |
| :--- | :--- | :--- |
| **目标搬迁日冲突** | 用户要求的搬迁日比默认 CPM 计算提前 15~30 天 | 启动 Zone A / Zone B 多流水段并行算法，将单流水优化为 `FS - 2d` 交叉流水段；调配 7~15 天物理战略缓冲池 |
| **跨春节大假冲突** | 搬迁目标位于春节元宵大假之后 | 启动**策略 A**（年前硬装粗保洁完工 + 春节假期长效强排通风）或**策略 B**（放宽前期设计 + 节后施工收口） |
| **大楼施工限制冲突** | 商业写字楼白天禁止噪音施工 | 拆分施工工序：白班进行无噪音管道铺设与接线，夜班（22:00~06:00）集中安排打孔与切割作业 |
